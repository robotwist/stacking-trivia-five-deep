## 🎮 Sneaky Deep Gameplay Mechanics

### **Visual Brain Mapping**
- Each completion lights up a neural node
- Related areas pulse when activated
- "Aha moment" animations when connections form
- Unexplored areas remain in shadow, creating exploration desire

### **The Conspiracy Wall**  
- Red string connections between completed stacks
- Players can manually draw connections they see
- Community voting on proposed connections
- Hidden connections revealed only after specific completion sequences

### **Academic Detective Mode**
- Present conflicting evidence
- Players must choose interpretations
- Scoring based on scholarly consensus vs. creative analysis
- "Publish or perish" pressure mechanics
